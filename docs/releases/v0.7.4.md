# PulseDeck 0.7.4 · Public preview

A Windows companion for the TURZX 8.8″ 1920×480 panel, with Desktop, Gaming and Spotify Music layouts.

This is an early development preview for the verified `chs_88inch.dev1_rom1.90` / USB `0525:A4A7` device. Other panel revisions are not yet supported. The interface is currently in Italian.

## What is included

- Configurable hardware widgets, rings, temperatures, power, fans, clocks and combined network rates.
- Steam/EA discovery, optional game artwork, process-session timer and PresentMon application FPS.
- Discord roster and optional Gaming speaking activity.
- Windows media, optional YouTube main-player extension and Spotify lyrics from LRCLIB.
- Larger Music cover art, playback status above the lyrics and synchronization details beside the lyrics attribution.
- Nine Music sensors, percentage-only RAM, Terminal tab titles and an installed Tux icon for WSL-prefixed tabs.
- Local configuration, encrypted credentials and bounded USB recovery.

## Install

Download and extract the complete **Windows x64** archive. Run `Start-PulseDeck.cmd`, then use the configurator at `http://127.0.0.1:5178`. CPU/motherboard/fan sensors may need PawnIO and elevation. Close the vendor TURZX software before connecting the physical panel.

See the [setup guide](https://github.com/cicarulez/PulseDeck/blob/main/docs/getting-started.md). The archive includes the .NET runtime, web configurator and native dependencies. The optional Electron wrapper is built separately.

## Known limits

- One verified display revision; approximately 1 Hz updates.
- FPS collection may need to be ready before an anti-cheat protected game starts.
- Voice activity needs a working Discord voice connection; mute/deaf is separate.
- Lyrics depend on a matching LRCLIB recording and only activate for the Spotify Windows session.
- Windows' aggregated browser media session is less precise without the optional extension.
- Aura color following, multiple displays and historical telemetry are not implemented.
- The package is not code-signed. SHA256SUMS detects mismatches but is not a publisher signature.
