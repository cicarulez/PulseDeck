# PulseDeck 0.10.2 — development snapshot

Updated 7 October 2026. This records the current source version; no tag, downloadable
0.10.2 archive or published release is implied. Existing downloaded/installed builds
can be older. Review [publishing](../publishing.md) before preparing a release.

## Changes

- The gaming profile keeps the saved panel brightness even when Aura Sync is on
  Dark (OFF), including when entering gaming while the panel is already dimmed.
- Leaving gaming makes the panel follow Aura's power state again. The exception
  applies to both automatic profile selection and manually selected gaming.
- Explicitly saved brightness values, including 0%, remain respected. Aura's
  reported state remains visible, and the configurator explains the exception.

## Verified results and limits

All 270 Core tests passed, including gaming transitions, forced gaming at startup
and brightness restoration. The Windows-targeted agent build succeeded with no
warnings or errors, and the Angular configurator production build succeeded.

The gaming exception has not yet been checked on the physical display or in a
signed-in Windows session. These checks did not deploy an updated Windows build.
See the [0.10.1 notes](v0.10.1.md) for the preceding music metadata changes.
