# PulseDeck 0.10.1 — development snapshot

Updated 6 October 2026. This records the current source version; no tag, downloadable
0.10.1 archive or published release is implied. Existing downloaded/installed builds
can be older. Review [publishing](../publishing.md) before preparing a release.

## Changes

- Music metadata uses the existing artist row: `Artists - Album (year)`, without
  adding another row or reducing the cover size.
- Album year comes from fresh Spotify metadata matching the current Windows media
  session. Missing album or year is omitted; unavailable values are not guessed.
- Long track titles and metadata scroll within their own area, with a two-second
  pause at the start and end. Changing tracks resets the scroll.
- Display metadata enrichment preserves the original lyrics lookup identity.

## Verified results and limits

268 Core tests, 26 Spotify tests and 69 renderer tests passed. The Windows-targeted
agent build succeeded with no warnings or errors. Renderer checks cover scrolling
bounds, the initial pause, track-change reset and rejection of stale or mismatched
Spotify metadata.

These changes have not yet been checked on the physical display or in a signed-in
Windows session. See the [0.10.0 notes](v0.10.0.md) for the preceding features and
their validation limits.
